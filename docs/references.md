# Tài liệu kỹ thuật tham khảo

- [Vite Getting Started](https://vite.dev/guide/): yêu cầu Node và cấu hình build/dev.
- [Tailwind với Vite](https://tailwindcss.com/docs/installation/using-vite): plugin Vite và CSS import.
- [GORM PostgreSQL](https://gorm.io/docs/connecting_to_the_database.html): driver, connection pool và context.
- [Gin](https://github.com/gin-gonic/gin): router/middleware; version thực tế được khóa trong was/go.mod.
- [golang-migrate](https://github.com/golang-migrate/migrate): migration runner và driver PostgreSQL.

Phiên bản thực tế lấy từ package manager và lockfile khi triển khai; không coi nhánh master tài liệu là version đã được cài.
